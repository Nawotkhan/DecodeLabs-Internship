# DecodeLabs-Internship
Detailed Statistical Data Analysis and Mining projects code files available in this repository.

## Project 1: Data Preprocessing and Cleaning
Applied basic analysis methods to clean and sort data as well as categorize it using LabelEncoder(). Data is prepared for descriptive analytics. 
### Skills Learnt : Data cleaning, Excel or Python basics, data preparation

## Project 2: Exploratory Data Analysis (EDA)
Analysed dataset to understand patterns, trends, and distributions.
Calculated basic statistics like mode, median, count and standard dev. Identified Outliers and different trends and provided a summary of key observations. 
### Skills Learnt : Data reading and analysis, descriptive statistics and analytical thinking

## Project 3: SQL Data Analysis
Using SQL queries to extract insights from dataset.
Write SQL queries like SELECT, WHERE, ORDER BY, GROUP BY and perform basic aggregations like COUNT, SUM and AVG.
### SQL fundamentals, querying data, filtering and grouping
